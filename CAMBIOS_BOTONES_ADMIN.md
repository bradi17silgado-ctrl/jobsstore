# Botones individuales dentro de Administración

- En `/admin` aparecen siete botones grandes, cada uno enlaza a una página independiente.
- Productos: `/admin/productos`; Agregar producto: `/admin/producto/nuevo`; Pedidos: `/admin/pedidos`; Ventas: `/admin/ventas`; Ingreso: `/admin/mercancia/entrada`; Salida: `/admin/mercancia/salida`; Historial: `/admin/movimientos`.
- Reseñas permanece disponible con un botón secundario.
- Se ha eliminado la barra de navegación duplicada de las subpáginas; el botón Volver al panel devuelve a `/admin`.
- No se modificaron lógica de inventario, pedidos, PDF ni tablas MySQL.
