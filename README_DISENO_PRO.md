JOBS Store - Rediseño profesional

Cambios: portada premium, tipografía y jerarquía visual, nueva paleta azul noche y dorado, tarjetas y categorías refinadas, ajustes responsive. Se mantienen rutas, carrito, catálogo, administración y WhatsApp.

Para publicar: reemplaza templates/index.html y static/style.css en tu repositorio, ejecuta git add . && git commit -m "Rediseño profesional JOBS Store" && git push origin main (si estás en main). Render desplegará según su configuración.
