
# Skill: Diseño Web Premium — JOBS Store

## Objetivo
Transformar JOBS Store en una tienda online
profesional, moderna y con identidad propia.

## Reglas de diseño
- Evitar diseños genéricos de Bootstrap.
- Crear componentes visuales personalizados.
- Utilizar una paleta elegante y consistente.
- Usar tipografía Inter o Manrope.
- Mantener espacios y tamaños equilibrados.
- Crear animaciones sutiles y funcionales.
- Diseñar primero para dispositivos móviles.
- Mantener una experiencia de compra intuitiva.

## Identidad visual
- Azul oscuro: #14213D
- Blanco: #FFFFFF
- Gris claro: #F5F7FA
- Dorado elegante: #D4AF37

## Componentes
- Encabezado personalizado.
- Menú lateral moderno.
- Carrito de compras accesible.
- Tarjetas de productos premium.
- Panel administrativo profesional.
- Formularios de compra modernos.
- Botón de WhatsApp visible.

## Restricciones
- No eliminar funcionalidades existentes.
- No modificar la lógica de negocio sin necesidad.
- Mantener la compatibilidad con PHP.
- Evitar diseños repetitivos o genéricos.
